# 🤖 AI Resume Screening Assistant

An AI-powered resume screening application built with Python and Streamlit.

## 🚀 Features

- 📄 Upload PDF resumes
- 🔍 Extract resume text
- 🤖 OCR support for scanned PDFs
- 📊 ATS keyword matching
- 🧠 AI semantic similarity analysis
- 💡 Skill relevance analysis
- ✅ Matched skills detection
- ❌ Missing skills detection
- 📈 Overall AI resume score
- 💡 Resume improvement recommendations

## 🛠️ Technologies Used

- Python
- Streamlit
- PyMuPDF
- Tesseract OCR
- Pytesseract
- Sentence Transformers
- Scikit-learn
- Pillow

## 📊 Resume Analysis

The application calculates an overall score using:

- 40% ATS score
- 30% Semantic similarity
- 30% Skill relevance
